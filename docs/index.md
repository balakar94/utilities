# Catalog

> Where to find each tool by need.

## How it is organized

Grouped by problem category, not by language. Categories here are hints for contributors;
the authoritative category of each tool lives in its `metadata.yaml`.

## Categories

### Automation

Good for: repeatable scripts.

### Text & data

Good for: convert, rename, clean.

### Network & system

Good for: diagnostics, health checks.

### Dev utilities

Good for: git, releases, CI.

## Full list

The complete, always-current catalog is generated in [`../TOOLS.md`](../TOOLS.md) by
`scripts/list-tools.sh`. Do not duplicate it here or in the root `README.md`.
